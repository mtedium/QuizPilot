# QuizPilot（答题助手）

作者 by mtedium · v0.4.0

多模块答题插件，同一套悬浮面板 UI，按网站自动启用对应模块。

## 模块

### 赛氪模块（`*.saikr.com`）

- 打开答题页自动显示面板（检测到题目才出现）
- **① 复制给 AI**：生成「提示词 + 全部题目（含题型标记）」并复制，丢给任意网页 AI 聊天
- **② 粘贴 AI 的回答**：粘贴 AI 的 JSON，点「填入」自动勾选答案
- 支持单选、多选、判断；多选答案连写（如 `"ACD"`）

### piclass 模块（`piclass.cn`）

- **作业详情页**：自动显示面板，两个标签页
  - **AI**：复制题目给 AI → 粘贴 JSON →「填入」后台逐题 POST 提交（不经过答题页），实时显示进度，完成后自动刷新
  - **题库**：用内置本地题库（6835 题）匹配全部题目，逐题列出命中状态（绿=命中/红=未命中），点「提交命中的题」只提交匹配上的；未命中的再去 AI 标签页兜底
- 题库匹配前会自动剥题号前缀和「（AI考点）」尾缀、统一标点，提高命中率
- 某题无答案则跳过并在结果中列出；已答过的题重新提交会覆盖旧答案

## AI 输出格式约定

```json
[{"题号":1,"答案":"A"},{"题号":2,"答案":"B"},{"题号":3,"答案":"ACD"}]
```

- 单选/判断一个字母
- 多选题（赛氪）选中字母连写
- 带 markdown 代码块的整段输出可直接粘贴

## 安装

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹

## 文件说明

插件按站点拆分为多个模块文件，`content_scripts` 按域名注入对应模块：

- `manifest.json` — 插件配置与注入规则
- `common.js` — 共用层：面板 UI、提示词生成、JSON 解析、复制（挂到 `window.QH`）
- `saikr.js` — 赛氪模块：题目提取、自动填入
- `piclass.js` — piclass 模块：题目提取、AI 批量提交、本地题库匹配
- `bank.js` — 本地题库数据（`window.QH_BANK`，由清洗脚本生成）

新增站点支持：加一个模块文件 + 在 manifest 里加一条 `content_scripts` 即可，共用层不用动。
